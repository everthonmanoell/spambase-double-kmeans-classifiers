## Decisões de Arquitetura: Classificador Janela de Parzen

* **Integração com o Ecossistema Scikit-Learn:** A classe customizada `ParzenWindowClassifier` herda de `BaseEstimator` e `ClassifierMixin`. Esta estrutura foi adotada para garantir compatibilidade nativa com o `GridSearchCV`, permitindo que o modelo seja injetado diretamente no pipeline de validação cruzada aninhada ($30 \times 10$-folds) exigido na Questão 2a, automatizando o ajuste da janela $h$ sem a necessidade de loops manuais de busca.
* **Mapeamento do Kernel Multivariado Produto:** O escopo do projeto demanda a aplicação de um kernel multivariado produto baseado no kernel gaussiano univariado[cite: 4]. Para isso, instanciou-se o `KernelDensity(kernel='gaussian')` separadamente para o subconjunto de dados de cada classe. Ao fornecer um parâmetro escalar único para a largura da janela (bandwidth $h$), a implementação realiza matematicamente o produto das densidades gaussianas univariadas independentes em todas as 57 dimensões, cumprindo o requisito de forma vetorizada e eficiente.
* **Estimativa de Máxima Verossimilhança das Priori:** O projeto especifica o uso da estimativa de máxima verossimilhança para a obtenção das probabilidades a priori $P(\omega_i)$. No método `.fit()`, isso foi rigorosamente implementado calculando a frequência relativa empírica de cada classe no conjunto de treinamento ($P(\omega_i) = \frac{N_i}{N_{total}}$).
* **Regra de Decisão no Espaço Logarítmico (Log-Space):** O método `.predict()` segue o Teorema de Bayes para alocar a amostra à classe com a maior probabilidade a posteriori. Para prevenir problemas críticos de *underflow* numérico — muito comuns ao multiplicar pequenas probabilidades de densidade em altas dimensões como a da base Spambase — a regra de decisão foi projetada para operar com somas no espaço logarítmico: $\arg\max_i (\log(p(x|\omega_i)) + \log(P(\omega_i)))$. Essa abordagem maximiza a estabilidade numérica extraindo diretamente a log-densidade através do método nativo `score_samples()`.
